# Aops-Desk: Injective Technical Architecture Specification
**Date:** 2026-09-28
**Maintainer:** 18Abhinav07

Aops-Desk is divided into three distinct operational layers:
1. **Control Layer (TypeScript)**: Web Console, Seat Listing templates, PEAGASIS conversational assistant.
2. **Enforcement Layer (CosmWasm / EVM Precompiles)**: Mandate contract holding AuthZ trading rights, running pre-order checks.
3. **Data Layer (Rust Indexer)**: Chain Stream consumer computing Deflated Sharpe Ratios from batch auction fills.
