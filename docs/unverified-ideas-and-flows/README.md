# Unverified Ideas & Flows

Drop zone for raw ideas, flows, and proposals from either collaborator (Ryuk or KC) or from
an AI session — before anything here has been structured, cross-checked against primary
sources, or reconciled against `docs/architecture/`.

## Rules

- **No structure required.** A half-formed idea, a voice-note transcript, a bullet list, a
  contradiction of something already decided elsewhere — all fine. The point of this folder
  is that nothing in it is binding on anything.
- **Nothing here blocks discussion of anything else.** An idea in this folder conflicting
  with `docs/architecture/` is not a problem to route around — it's exactly what this folder
  is for. Conflicts get resolved in conversation, not by one side silently winning because it
  was written down first.
- **One file per idea/session is fine — don't over-organize.** Suggested naming:
  `YYYY-MM-DD-short-topic-<author-initials>.md` (e.g. `2026-08-24-fraud-sybil-signals-ryuk.md`),
  but this isn't enforced.
- **Promotion path**: once an idea is discussed, confirmed, and cross-checked, it gets written
  up properly in `docs/architecture/` (structured, verified, still refinable) — and the
  originating file here can stay as-is (historical record) or be deleted once fully absorbed.
  Don't delete it just to tidy up if it still has un-absorbed detail.
- **Never edited by someone other than its author to "correct" it** — if an idea here turns
  out wrong, that gets resolved in `docs/architecture/`, not by rewriting history in this
  folder.
